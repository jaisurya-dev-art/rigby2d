# Rigby2D brand kit

The Rigby2D logo, cropped to the artwork, as SVG and as transparent PNG.

| File | Use |
| --- | --- |
| `rigby2d-r` | The R logo, for dark backgrounds (the standard logo) |
| `rigby2d-r-light` | The R logo, for white and light backgrounds |
| `rigby2d-r-white` | The R in white, for black backgrounds and photos |
| `rigby2d-r-black` | The R in black, for white backgrounds and print |
| `rigby2d-logo` | The R with the name, for dark backgrounds |
| `rigby2d-logo-light` | The R with the name, for white and light backgrounds |

## Colours

| Name | Hex |
| --- | --- |
| Night | `#0A0A0B` |
| Snow | `#F4F4F5` |
| Ice | `#B5D3E7` |
| Steel | `#7BA7C7` |
| Deep steel | `#3F6E91` |
| Ember | `#F08A3A` |

The name is written **Rigby2D**: one word, a capital R and D. The wordmark is set in Inter.

## Using the logo

- Use the logo to point to Rigby2D: in an article, a video, a tutorial, or the credits of a game
  made with it.
- Keep a clear space around it of at least a quarter of the R's height.
- Use the version made for your background. On photos or busy art, use the white or black R.
- Don't recolour, stretch, rotate, outline or rearrange it, or add effects.
- Don't use it in a way that suggests the Rigby2D project made or endorses your product.
