## Funciones

- **AutoRig**: un PSD por capas se convierte en un rig editable en un paso: huesos, articulaciones, mallas que se doblan e IK.
- **Herramientas de montaje completas**: huesos, mallas con pesos, mallas enlazadas, secuencias de imágenes, skins, eventos, recortes y trayectorias, con restricciones IK, de transformación, de trayectoria, de física y de deslizador.
- **Animación**: modos Setup y Animate, hoja de animación, editor de curvas con manejadores Bézier, papel cebolla, biblioteca de poses, controles faciales y redirección de animaciones entre personajes.
- **Espacio de película**: 4K, código de tiempo, cámara animable, pistas de audio, sincronía labial por visemas con transcripción Whisper en el propio equipo, y render a secuencias PNG, WebM con transparencia y MP4.
- **Composición de escenas**: varios personajes en un escenario como actores con clips al estilo de un editor de vídeo (recorte, velocidad, bucles, fundidos, su propio audio), capas pintadas con paralaje y una cámara; se reproducen en juegos con todos los runtimes.
- **Tu trabajo está a salvo**: guardados que nunca dejan un archivo a medias, copias `.rigby1` como el `.blend1` de Blender, autoguardado y recuperación tras fallos que te devuelve el trabajo sin guardar al volver a abrir.
- **Pantalla de bienvenida, actualización automática y runtimes desde el editor**: proyectos nuevos, trabajo reciente, proyectos iniciales y lecciones al iniciar; actualizaciones firmadas en la app de escritorio; *Archivo ▸ Obtener runtimes* para Unity, Godot y Phaser.
- **Preferencias y complementos**: idioma (inglés, japonés, chino, coreano, español, portugués), escala de la interfaz, atajos, pasos de deshacer, copias y autoguardado, y una galería de complementos en Python que se ejecutan aislados.
- **Desde otras herramientas**: abre exportaciones de Spine (con un comprobador de migración) y proyectos de DragonBones.
- **Scripts en Python** y herramientas propias, y un **servidor MCP** integrado para que asistentes de IA como Claude inspeccionen, monten y animen tus proyectos.
- **JSON de esqueleto (3.8, 4.2, 4.3) y `.skel` binario sin pérdidas**, con atlas de texturas, reproducidos por los **runtimes de JavaScript, Phaser, Rust, Unity y Godot**.
- **Tutoriales** y proyectos de demostración integrados (**NILA**, **Rigbytron** y una **escena** con ambos), también en la [página de demos](https://rigby2d.com/demos/) con sus exportaciones para juegos (contenido de demostración © Rigby2D, bajo su propia [licencia de demos](branding/DEMO-LICENSE.md)).

## Primeros pasos

- **En el navegador:** [abre el editor](https://rigby2d.com/editor/), sin instalar nada.
- **Windows:** [descarga el editor portátil](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D_x64_portable.exe) o un instalador desde [Releases](https://github.com/jaisurya-dev-art/rigby2d/releases).
- **macOS:** [descarga el .dmg](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D_universal.dmg) (Apple silicon e Intel). La primera vez, clic derecho ▸ Abrir (ver [Instalación](https://rigby2d.com/docs/installation.html)).
- **Linux:** [descarga el AppImage](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D_amd64.AppImage) o el `.deb` desde [Releases](https://github.com/jaisurya-dev-art/rigby2d/releases).
- **Asistentes de IA:** instala [Rigby2D-AI.mcpb](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D-AI.mcpb) en Claude Desktop, o consulta la [guía de MCP](https://rigby2d.com/docs/mcp.html).
- **Desde el código fuente** (Node.js 20+ y los [requisitos de Tauri](https://tauri.app/start/prerequisites/)):

```bash
git clone https://github.com/jaisurya-dev-art/rigby2d.git
cd rigby2d
npm install
npm run dev        # app de escritorio; npm run web:dev para el navegador, npm test para las pruebas
```

## Estructura del proyecto

```
src/core/       Runtime: modelo de datos, E/S de JSON/.skel y atlas, cálculo de poses, restricciones, reproducción
src/editor/     Interfaz del editor: vista, árbol, inspector, hoja de animación, editor de curvas, importar/exportar, scripts
src/webgl/      Renderizador WebGL de referencia para el runtime
src/mcp/        Servidor Model Context Protocol para asistentes de IA
runtimes/       Runtimes de Rust, Godot, Unity y Phaser
addons/         Complementos oficiales
site/           Sitio web y sitio de documentación (GitHub Pages)
docs/           Páginas e imágenes de la documentación
branding/       Logo, iconos, Rigbytron y NILA (propietarios, ver TRADEMARKS.md)
src-tauri/      Envoltorio nativo de escritorio
test/           Pruebas con node:test
```
