Rigby2D 0.4 is our biggest release yet. [Download it](https://github.com/jaisurya-dev-art/rigby2d/releases/tag/v0.4.0).

## Every desktop

Native apps for Windows, macOS (one universal build for Apple silicon and Intel) and Linux
(AppImage and `.deb`), built in the open by GitHub Actions.

## Unity and Phaser runtimes

- **Unity** 2021.3 and newer, Unity 6 included, with the Built-in and Universal render pipelines. It
  uses every core and makes no garbage: 200 NILAs take 5 ms a frame in an IL2CPP player on a 4-core
  laptop. [Unity guide](https://github.com/jaisurya-dev-art/rigby2d/blob/develop/runtimes/unity/com.rigby2d.unity/README.md).
- **Phaser** 3.60 and newer: `this.load.rigby()` and `this.add.rigby()`.
  [Phaser guide](https://github.com/jaisurya-dev-art/rigby2d/blob/develop/runtimes/phaser/README.md).
- **Godot** now ships for Windows, macOS and Linux.

All of them are free to ship, and play your animation exactly as the editor does.

## Your work is safe

- Saves never leave a half-written file.
- Each save keeps the previous version as `walk.rigby1`, like Blender's `.blend1`.
- Unsaved work is auto-saved, and offered back after a crash.
- Closing with unsaved changes asks first.

## Preferences and add-ons

*Edit ▸ Preferences* (Ctrl+,) for the interface scale, shortcuts, undo steps, backups and
auto-save, and the first add-on installer: Python packages that add tools to the Scripts menu.
