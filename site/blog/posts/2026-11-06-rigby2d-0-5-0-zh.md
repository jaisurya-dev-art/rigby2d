多年来，为游戏制作 2D 骨骼动画总要先付一笔入场费：网格和 IK 需要售价 379 美元的 Spine
Professional，游戏还没发布，就得先买授权。Rigby2D 的回答始终如一：所有功能免费，所有运行时免费
随游戏发布，完全开源。0.5 让这个回答覆盖得比以往任何时候都更广。

[下载 0.5](https://github.com/jaisurya-dev-art/rigby2d/releases/tag/v0.5.0)，让编辑器自动更新，
或者[在浏览器中打开](https://rigby2d.com/editor/)（无需安装，界面支持简体中文）。
[English](/blog/rigby2d-0-5-0.html)

## 0.5 的新内容

- **原生 Defold 运行时。** 使用 C++ 编写，覆盖 Defold 支持的所有平台：Windows、macOS、Linux、
  Android、iOS 和 HTML5，与编辑器逐帧一致。作为库添加后，即可播放网格、IK、物理、皮肤和场景。
  [开发过程](/blog/defold-and-sprite-sheets-zh.html)。
- **GPU 加速的精灵图导出。** 导出带 JSON 的打包精灵图（适用于 Phaser 和 PixiJS）、Defold 图集，
  或逐帧 PNG。单张放不下的精灵图会自动拆分成多张，导出前还会先告诉你尺寸。
- **SVG 导入。** Inkscape 和 Affinity 的作品按图层导入，每个部件都在你画它的位置，可以直接用
  AutoRig 绑定。这个功能源自 [r/rigby2d 上的一个帖子](/blog/two-posts-two-features.html)。
- **从图片生成网格。** 一键描出图像轮廓、放置顶点并生成三角形，然后就可以让它弯曲变形。
- **Godot 运行时可用于正式项目。** RigbySkeleton2D 和 RigbyScene2D 已结束预览。
- **更多改进：** 自定义快捷键、在时间轴中复制粘贴关键帧、分层 PNG 自动就位、在浏览器版编辑器中通过
  选择或拖入文件打开项目、每次导出后显示结果对话框，以及支持 Phaser 4。

现在共有七个运行时可以播放你在 Rigby2D 中制作的内容，而且每一个都与同一个参考实现对照测试：
[七个运行时，同一个答案](/blog/seven-runtimes-one-answer-zh.html)。

## 带上你的 Spine 和 DragonBones 项目

Rigby2D 可以无损打开 Spine 导出文件（JSON 和 `.skel`，3.8 到 4.3），也能连同图集一起打开
DragonBones 项目。切换之前，*文件 ▸ 导入 ▸ 检查骨骼文件* 会告诉你哪些内容可以完整迁移。迁移指南：
[从 Spine 迁移](https://rigby2d.com/docs/migrating-from-spine.html)和
[从 DragonBones 迁移](https://rigby2d.com/docs/migrating-from-dragonbones.html)（英文）。

## 获取

- **桌面版：** [Windows、macOS 和 Linux](https://github.com/jaisurya-dev-art/rigby2d/releases/tag/v0.5.0)。
  如果你正在使用 0.4，编辑器会自动提示更新。
- **浏览器版：** [rigby2d.com/editor](https://rigby2d.com/editor/)，无需安装。
- **运行时：** Unity、Godot、Defold、Cocos Creator、Phaser、JavaScript 和 Rust，可在
  [运行时页面](https://rigby2d.com/runtimes/)下载，或在编辑器中通过 *文件 ▸ 获取运行时* 获取。
