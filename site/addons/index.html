Add-ons

Add tools to the editor

Add-ons are small Python packages that add tools to the Scripts menu. Install them in the editor from Edit ▸ Preferences ▸ Add-ons ▸ Get add-ons, or download one here and choose Install from file…. They run sandboxed: they can change the open project, but not your files or the network.

Made an add-on? Write one, then list it with a pull request to addons/gallery.json.
