Publish

Share your add-on

Publishing is free. Your code stays in your own GitHub repository; the registry lists it here and in every editor's gallery, and picks up each new release by itself.

  1. Write itA Python package with addon_info and register(). Start from an official add-on and the guide.
  2. Put it on GitHubA public repository with a LICENSE. Publish a release (attach a .zip, or let GitHub zip the tag).
  3. Submit itFill in the form. Automatic checks run at once; after a quick review it is listed here and in the editor.
  4. Ship updatesBump the version in addon_info and publish a release. The registry picks it up within a few hours.
