    Questions

    Good to know.

    Will Rigby2D stay free?

    Yes. The editor, the runtimes and the file formats are open source (MIT or Apache-2.0) and free to use in commercial games and films, with no runtime fees. Support never unlocks features.

    Why does code signing need money?

    Windows and macOS warn about apps from unknown publishers. Removing that warning means a certificate tied to Rigby2D's name, renewed every year, plus Apple's yearly developer membership. It's the most visible thing standing between Rigby2D and a new user.

    Can my studio sponsor?

    Yes. GitHub Sponsors works for organizations too, and the Studio tiers put your logo in the README and here. For anything else, write to hello@rigby2d.com.

    Other ways to help

    Star the project on GitHub, share what you make on r/rigby2d, report bugs, write an add-on, or send a pull request. All of it counts.
