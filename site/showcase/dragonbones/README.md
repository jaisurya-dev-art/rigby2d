# DragonBones demo characters

The characters in the "Coming from DragonBones" section of rigby2d.com: four of DragonBones' own demo
characters, loaded from their DragonBones export files (`_ske.json`, `_tex.json`, `_tex.png`) and
played with the Rigby2D runtime in the browser.
