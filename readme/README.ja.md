## 主な機能

- **AutoRig**：レイヤー分けされた PSD を一度で編集可能なリグに。ボーン、関節、曲がるメッシュ、IK まで。
- **本格的なリギングツール**：ボーン、ウェイト付きメッシュ、リンクメッシュ、画像シーケンス、スキン、イベント、クリッピング、パス。IK、トランスフォーム、パス、物理、スライダーのコンストレイント。
- **アニメーション**：セットアップ／アニメートモード、ドープシート、ベジェハンドル付きグラフエディター、オニオンスキン、ポーズライブラリ、表情コントロール、キャラクター間のリターゲット。
- **フィルムワークスペース**：4K、タイムコード、アニメーション可能なカメラ、オーディオトラック、端末内の Whisper 文字起こしによるビズィームリップシンク。PNG 連番、透過 WebM、MP4 に書き出し。
- **シーン構成**：複数のキャラクターを 1 つのステージに配置し、NLE 風のクリップ（トリム、速度、ループ、クロスフェード、個別の音声）、視差付きの背景レイヤー、カメラで演出。すべてのランタイムでゲームでも再生できます。
- **作業を守る仕組み**：書きかけのファイルを残さない安全な保存、Blender の `.blend1` のような `.rigby1` バックアップ、自動保存、次回起動時に未保存の作業を戻せるクラッシュ復元。
- **ようこそ画面・自動アップデート・ランタイム入手**：起動時に新規プロジェクト、最近の作業、スタータープロジェクト、レッスン。デスクトップ版は署名付きアップデート。*ファイル ▸ ランタイムを入手* で Unity・Godot・Phaser 用ランタイム。
- **環境設定とアドオン**：言語（英語、日本語、中国語、韓国語、スペイン語、ポルトガル語）、インターフェースの拡大率、ショートカット、元に戻す回数、バックアップ、自動保存。サンドボックスで動く Python アドオンのギャラリー。
- **他のツールからの移行**：Spine の書き出しファイル（移行チェッカー付き）と DragonBones のプロジェクトを開けます。
- **Python スクリプト**とカスタムツール、そして Claude などの AI アシスタントがプロジェクトを調べ、リグし、アニメーションできる **MCP サーバー**を内蔵。
- **ロスレスなスケルトン JSON（3.8、4.2、4.3）とバイナリ `.skel`**、テクスチャアトラス。**JavaScript、Phaser、Rust、Unity、Godot のランタイム**で再生。
- **チュートリアル**とデモプロジェクト（**NILA**、**Rigbytron**、2 人の**シーン**）を内蔵。[デモページ](https://rigby2d.com/demos/)ではゲーム用の書き出しデータも配布（デモコンテンツ © Rigby2D、[デモライセンス](../branding/DEMO-LICENSE.md)）。

## はじめ方

- **ブラウザーで：**[エディターを開く](https://rigby2d.com/editor/)。インストール不要です。
- **Windows：**[ポータブル版をダウンロード](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D_x64_portable.exe)、または [Releases](https://github.com/jaisurya-dev-art/rigby2d/releases) からインストーラー。
- **macOS：**[.dmg をダウンロード](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D_universal.dmg)（Apple シリコンと Intel）。初回は右クリック ▸ 開く（[インストール方法](https://rigby2d.com/docs/installation.html)）。
- **Linux：**[AppImage をダウンロード](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D_amd64.AppImage)、または [Releases](https://github.com/jaisurya-dev-art/rigby2d/releases) から `.deb`。
- **AI アシスタント：**[Rigby2D-AI.mcpb](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D-AI.mcpb) を Claude Desktop にインストール、または [MCP ガイド](https://rigby2d.com/docs/mcp.html) を参照。
- **ソースから**（Node.js 20 以上と [Tauri の前提条件](https://tauri.app/start/prerequisites/)）：

```bash
git clone https://github.com/jaisurya-dev-art/rigby2d.git
cd rigby2d
npm install
npm run dev        # デスクトップ版。ブラウザー版は npm run web:dev、テストは npm test
```

## プロジェクト構成

```
src/core/       ランタイム：データモデル、スケルトン JSON/.skel とアトラスの入出力、ポーズ計算、コンストレイント、再生
src/editor/     エディター UI：ビューポート、ツリー、インスペクター、ドープシート、グラフエディター、入出力、スクリプト
src/webgl/      ランタイム用のリファレンス WebGL レンダラー
src/mcp/        AI アシスタント向けの Model Context Protocol サーバー
runtimes/       Rust、Godot、Unity、Phaser のランタイム
addons/         公式アドオン
site/           Web サイトとドキュメントサイト（GitHub Pages）
docs/           ドキュメントのページと画像
branding/       ロゴ、アイコン、Rigbytron と NILA（独占的権利あり、TRADEMARKS.md を参照）
src-tauri/      ネイティブのデスクトップシェル
test/           node:test のテスト
```
