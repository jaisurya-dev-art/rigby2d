# Keyboard shortcuts

Rigby2D has two shortcut presets. Choose one under *View ▸ Shortcuts*; *Help ▸ Keyboard shortcuts*
lists the keys of the active preset, with a search box and the preset switch. On macOS, <kbd>Ctrl</kbd> also works as <kbd>Cmd</kbd>.

- **Reference** (default): tools and playback on the left hand (B, N, C, V, X, Z; Q, W, E, A, S, D,
  R, F), as in common 2D animation tools.
- **Blender-like**: G, R, S for translate, rotate and scale, I to key, the arrow keys for time.

This table is generated from the editor's keymap, so it always matches the current version.

## Mouse

| Where | Action | Does |
| --- | --- | --- |
| Viewport | Click | Select a bone or image. |
| Viewport | <kbd>Ctrl</kbd>+click | Add to or remove from the selection. |
| Viewport | Drag empty space | Box select (or transform the selection with a transform tool). |
| Viewport | Right or middle drag | Pan. |
| Viewport | Wheel | Zoom. |
| Dopesheet | Click / <kbd>Ctrl</kbd>+click / drag a box | Select keys. |
| Dopesheet | Drag a key | Move the selected keys. |
| Dopesheet | Drag a selection edge in the ruler | Retime the selected keys. |
| Dopesheet, graph | Right-click a key | Curve presets and delete. |
| Graph | Wheel / <kbd>Shift</kbd>+wheel | Zoom / pan values. |
| Graph | <kbd>Ctrl</kbd>+wheel / <kbd>Alt</kbd>+wheel | Zoom / pan time. |
| Graph | Double-click | Fit the curves. |
| Graph | <kbd>Alt</kbd>+drag a handle | Move one handle on its own. |
| Mesh vertices | <kbd>Ctrl</kbd>+click / <kbd>Ctrl</kbd>+drag | Select several vertices. |
| Mesh weights | <kbd>Shift</kbd>+drag | Subtract weight. |
