## Recursos

- **AutoRig**: um PSD em camadas vira um rig editável em um passo: ossos, articulações, malhas que dobram e IK.
- **Ferramentas de rig completas**: ossos, malhas com pesos, malhas vinculadas, sequências de imagens, skins, eventos, recortes e caminhos, com restrições de IK, transformação, caminho, física e controle deslizante.
- **Animação**: modos Setup e Animate, folha de animação, editor de curvas com alças Bézier, papel cebola, biblioteca de poses, controles faciais e redirecionamento de animações entre personagens.
- **Espaço de filme**: 4K, timecode, câmera animável, faixas de áudio, sincronia labial por visemas com transcrição Whisper no próprio computador, e renderização em sequências PNG, WebM com transparência e MP4.
- **Composição de cenas**: vários personagens em um palco como atores com clipes no estilo de editor de vídeo (corte, velocidade, loops, transições, áudio próprio), camadas pintadas com paralaxe e uma câmera; reproduzidas em jogos por todos os runtimes.
- **Seu trabalho está seguro**: salvamentos que nunca deixam um arquivo pela metade, backups `.rigby1` como o `.blend1` do Blender, salvamento automático e recuperação após falhas que devolve o trabalho não salvo na próxima abertura.
- **Tela de boas-vindas, atualização automática e runtimes pelo editor**: novos projetos, trabalhos recentes, projetos iniciais e lições ao abrir; atualizações assinadas no app para desktop; *Arquivo ▸ Obter runtimes* para Unity, Godot e Phaser.
- **Preferências e complementos**: idioma (inglês, japonês, chinês, coreano, espanhol, português), escala da interface, atalhos, passos de desfazer, backups e salvamento automático, e uma galeria de complementos em Python que rodam isolados.
- **Vindo de outras ferramentas**: abre exportações do Spine (com um verificador de migração) e projetos do DragonBones.
- **Scripts em Python** e ferramentas próprias, e um **servidor MCP** integrado para que assistentes de IA como o Claude inspecionem, façam o rig e animem seus projetos.
- **JSON de esqueleto (3.8, 4.2, 4.3) e `.skel` binário sem perdas**, com atlas de texturas, reproduzidos pelos **runtimes JavaScript, Phaser, Rust, Unity e Godot**.
- **Tutoriais** e projetos de demonstração integrados (**NILA**, **Rigbytron** e uma **cena** com os dois), também na [página de demos](https://rigby2d.com/demos/) com as exportações prontas para jogos (conteúdo de demonstração © Rigby2D, sob a própria [licença de demos](branding/DEMO-LICENSE.md)).

## Como começar

- **No navegador:** [abra o editor](https://rigby2d.com/editor/), sem instalar nada.
- **Windows:** [baixe o editor portátil](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D_x64_portable.exe) ou um instalador em [Releases](https://github.com/jaisurya-dev-art/rigby2d/releases).
- **macOS:** [baixe o .dmg](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D_universal.dmg) (Apple silicon e Intel). Na primeira vez, clique com o botão direito ▸ Abrir (veja [Instalação](https://rigby2d.com/docs/installation.html)).
- **Linux:** [baixe o AppImage](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D_amd64.AppImage) ou o `.deb` em [Releases](https://github.com/jaisurya-dev-art/rigby2d/releases).
- **Assistentes de IA:** instale o [Rigby2D-AI.mcpb](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D-AI.mcpb) no Claude Desktop, ou veja o [guia do MCP](https://rigby2d.com/docs/mcp.html).
- **A partir do código-fonte** (Node.js 20+ e os [pré-requisitos do Tauri](https://tauri.app/start/prerequisites/)):

```bash
git clone https://github.com/jaisurya-dev-art/rigby2d.git
cd rigby2d
npm install
npm run dev        # app para desktop; npm run web:dev para o navegador, npm test para os testes
```

## Estrutura do projeto

```
src/core/       Runtime: modelo de dados, E/S de JSON/.skel e atlas, cálculo de poses, restrições, reprodução
src/editor/     Interface do editor: viewport, árvore, inspetor, folha de animação, editor de curvas, importar/exportar, scripts
src/webgl/      Renderizador WebGL de referência para o runtime
src/mcp/        Servidor Model Context Protocol para assistentes de IA
runtimes/       Runtimes Rust, Godot, Unity e Phaser
addons/         Complementos oficiais
site/           Site e site de documentação (GitHub Pages)
docs/           Páginas e imagens da documentação
branding/       Logo, ícones, Rigbytron e NILA (proprietários, veja TRADEMARKS.md)
src-tauri/      Shell nativo para desktop
test/           Testes com node:test
```
