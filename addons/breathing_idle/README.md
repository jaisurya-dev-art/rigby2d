# Breathing idle

A looping "breathe" animation in one click, ready to play under other animations.

## Tools

In the **Scripts** menu:

- **Make a breathing idle**: adds a 2.4-second animation named `breathe` (or `breathe 2`, … when
  that name is taken). The selected bones swell and settle; with nothing selected, it uses the bones
  named chest, spine, torso or body. Head and neck bones tilt a little with each breath.

The animation starts and ends on the same pose, so it loops cleanly. Play it on its own track to
keep a character alive while it stands still.
