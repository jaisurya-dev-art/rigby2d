# Official add-ons

Python add-ons for Rigby2D, listed in the add-on gallery (*Edit ▸ Preferences ▸ Add-ons ▸ Get
add-ons*) and on [rigby2d.com/addons](https://rigby2d.com/addons/). Each folder is one add-on
package, with an entry in [registry/addons](../registry/addons); the website build zips it.

Community add-ons live in their own repositories and are listed through the add-on registry
([registry/](../registry)). To publish yours, see
[Publishing](../docs/addons.md#publishing).
