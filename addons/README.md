# Official add-ons

Python add-ons for Rigby2D, published in the add-on gallery (*Edit ▸ Preferences ▸ Add-ons ▸ Get
add-ons*) and on [rigby2d.com/addons](https://rigby2d.com/addons/). Each folder is one add-on
package; the website build zips it (`site/vite.config.js`). `gallery.json` lists the gallery,
including add-ons hosted elsewhere.

To list your own add-on, open a pull request that adds it to `gallery.json` with a `url` to its
`.zip` (a GitHub release file, for example). See [Add-ons](../docs/addons.md) for the format.
