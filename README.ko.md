## 기능

- **AutoRig**: 레이어가 나뉜 PSD를 한 번에 편집 가능한 리그로: 본, 관절, 휘어지는 메시, IK까지.
- **완전한 리깅 도구**: 본, 웨이트 메시, 링크된 메시, 이미지 시퀀스, 스킨, 이벤트, 클리핑, 패스. IK, 변형, 패스, 물리, 슬라이더 제약.
- **애니메이션**: 셋업/애니메이트 모드, 도프시트, 베지어 핸들이 있는 그래프 에디터, 어니언 스킨, 포즈 라이브러리, 표정 컨트롤, 캐릭터 간 리타깃.
- **필름 작업 공간**: 4K, 타임코드, 애니메이션 가능한 카메라, 오디오 트랙, 기기 내 Whisper 전사를 이용한 비짐 립싱크. PNG 시퀀스, 투명 WebM, MP4로 렌더링.
- **씬 구성**: 여러 캐릭터를 한 무대에 배우로 배치하고 NLE 방식의 클립(트림, 속도, 반복, 크로스페이드, 개별 오디오), 시차가 있는 배경 레이어, 카메라로 연출. 모든 런타임으로 게임에서도 재생됩니다.
- **작업 보호**: 반쯤 쓰인 파일을 남기지 않는 안전한 저장, Blender의 `.blend1` 같은 `.rigby1` 백업, 자동 저장, 다음 실행 때 저장하지 않은 작업을 되돌려 주는 충돌 복구.
- **시작 화면, 자동 업데이트, 런타임 받기**: 실행 시 새 프로젝트, 최근 작업, 스타터 프로젝트, 레슨. 데스크톱 앱은 서명된 업데이트. *파일 ▸ 런타임 받기*로 Unity, Godot, Phaser 런타임.
- **환경설정과 애드온**: 언어(영어, 일본어, 중국어, 한국어, 스페인어, 포르투갈어), 인터페이스 배율, 단축키, 실행 취소 단계, 백업, 자동 저장, 샌드박스에서 실행되는 Python 애드온 갤러리.
- **다른 도구에서 옮기기**: Spine 내보내기 파일(마이그레이션 검사기 포함)과 DragonBones 프로젝트를 엽니다.
- **Python 스크립트**와 사용자 도구, 그리고 Claude 같은 AI 어시스턴트가 프로젝트를 살펴보고 리깅하고 애니메이션할 수 있는 **MCP 서버** 내장.
- **손실 없는 스켈레톤 JSON(3.8, 4.2, 4.3)과 바이너리 `.skel`**, 텍스처 아틀라스. **JavaScript, Phaser, Rust, Unity, Godot 런타임**으로 재생.
- **튜토리얼**과 데모 프로젝트(**NILA**, **Rigbytron**, 두 캐릭터의 **씬**) 내장. [데모 페이지](https://rigby2d.com/demos/)에서 게임용 내보내기 파일도 제공(데모 콘텐츠 © Rigby2D, [데모 라이선스](branding/DEMO-LICENSE.md)).

## 시작하기

- **브라우저에서:** [에디터 열기](https://rigby2d.com/editor/), 설치 필요 없음.
- **Windows:** [포터블 버전 다운로드](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D_x64_portable.exe) 또는 [Releases](https://github.com/jaisurya-dev-art/rigby2d/releases)에서 설치 프로그램.
- **macOS:** [.dmg 다운로드](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D_universal.dmg)(Apple 실리콘과 Intel). 처음 열 때는 오른쪽 클릭 ▸ 열기([설치 안내](https://rigby2d.com/docs/installation.html)).
- **Linux:** [AppImage 다운로드](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D_amd64.AppImage) 또는 [Releases](https://github.com/jaisurya-dev-art/rigby2d/releases)에서 `.deb`.
- **AI 어시스턴트:** Claude Desktop에 [Rigby2D-AI.mcpb](https://github.com/jaisurya-dev-art/rigby2d/releases/latest/download/Rigby2D-AI.mcpb) 설치, 또는 [MCP 가이드](https://rigby2d.com/docs/mcp.html) 참고.
- **소스에서**(Node.js 20 이상과 [Tauri 사전 요구 사항](https://tauri.app/start/prerequisites/)):

```bash
git clone https://github.com/jaisurya-dev-art/rigby2d.git
cd rigby2d
npm install
npm run dev        # 데스크톱 앱. 브라우저는 npm run web:dev, 테스트는 npm test
```

## 프로젝트 구조

```
src/core/       런타임: 데이터 모델, 스켈레톤 JSON/.skel과 아틀라스 입출력, 포즈 계산, 제약, 재생
src/editor/     에디터 UI: 뷰포트, 트리, 인스펙터, 도프시트, 그래프 에디터, 가져오기/내보내기, 스크립트
src/webgl/      런타임용 레퍼런스 WebGL 렌더러
src/mcp/        AI 어시스턴트를 위한 Model Context Protocol 서버
runtimes/       Rust, Godot, Unity, Phaser 런타임
addons/         공식 애드온
site/           웹사이트와 문서 사이트(GitHub Pages)
docs/           문서 페이지와 이미지
branding/       로고, 아이콘, Rigbytron과 NILA(독점, TRADEMARKS.md 참고)
src-tauri/      네이티브 데스크톱 셸
test/           node:test 테스트
```
